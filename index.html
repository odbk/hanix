// ianix

IA local que enseña, no que ataca sola

IAnix es un asistente de comandos con un modelo de lenguaje (Qwen3-4B) horneado dentro de la propia imagen. Funciona 100% offline desde el primer arranque —sin Ollama, sin API keys, sin que nada salga de tu máquina—. Le describes la tarea en español y te escribe el comando; con -v te explica qué hace y para qué sirve cada argumento. Pensado para aprender, no para atacar en piloto automático.

ianix -v 
hanix@live ~ $ ianix -v cuál es mi ip pública
⏱ IA: 2.1s

  [A] curl -s https://ifconfig.me   · por defecto (Enter)
      Consulta un servicio externo y muestra la IP pública con la que sales a Internet.
        curl                   cliente HTTP
        -s                     modo silencioso, sin barra de progreso
        https://ifconfig.me    servicio externo que devuelve tu IP pública

Pulsa Enter para ejecutar · una letra para otra opción · q para cancelar
📴
OFFLINE DE FÁBRICA
El modelo va dentro de la ISO. Cero nube, cero API keys, cero ollama pull. Air-gapped al instante.
🎓
APRENDE EL PORQUÉ
Con -v explica cada flag (p. ej. -sV = detecta servicio y versión). No es una caja negra.
🛡
SEGURO POR DISEÑO
Ejecuta como lista de argumentos, sin intérprete de shell. Tú confirmas con Enter; lo destructivo pide un extra.
🧭
CONSCIENTE DEL SISTEMA
Conoce las herramientas instaladas y las rutas reales (SecLists, rockyou, plantillas de nuclei). Nada de rutas inventadas.

// arranque

En marcha en 3 pasos

1

Descarga la ISO

Descarga hanix.iso desde el botón de arriba o clona el repo y compila con Nix.

nix build github:odbk/hanix#iso
2

Graba en USB

Usa dd o cualquier grabador de imágenes. Compatible con UEFI y BIOS.

sudo dd if=hanix.iso of=/dev/sdX bs=4M status=progress
3

Arranca y hackea

Arranca desde USB. Login automático con usuario hanix / contraseña hanix, exclusivos del entorno live. El instalador crea credenciales distintas para el sistema final.

// mantenimiento

Mantenerse actualizado

Una vez instalado, puedes seguir los cambios del proyecto sin necesidad de reinstalar.

1

Añade el remoto (solo una vez)

cd ~/hanix git remote add origin https://github.com/odbk/hanix git fetch origin git branch --set-upstream-to=origin/main main
2

Actualiza cuando quieras

git pull && ./rebuild
// para los que saben git
El instalador genera un repo local con tu personal.nix y hardware-configuration.nix. El primero queda marcado como skip-worktree; el segundo describe el hardware y los discos concretos de esa máquina. Si personalizas otros archivos, commitéalos localmente antes de hacer git pull para evitar conflictos. No hace falta push a ningún sitio — tus cambios se quedan en tu máquina.
